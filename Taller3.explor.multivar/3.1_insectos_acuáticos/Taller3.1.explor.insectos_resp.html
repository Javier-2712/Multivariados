Exploración gráfica multivariada - base Insectos

📋 Instrucciones

Este taller enfatiza el entrenamiento de gráficos exploratorios (univariados, bivariados y multivariados), orientado en la identificación de patrones (p. ej. gradientes, dominancia de taxones, heterogeneidad ambiental, asociaciones bióticas y abióticas, identificación de valores atípicos) a partir de una manipulación apropiada de los datos. La lógica de trabajo consiste en (1) preparar y revisar datos, (2) elegir figuras que responden a la pregunta definida, (3) interpretar los patrones y (4) documentar los resultados.

Introducción

En estudios ecológicos y ambientales, la visualización de los datos corresponde a una fase estructurante del razonamiento ecológico cuantitativo, permitiendo reconocer patrones espaciales y/o temporales directamente de diferentes escalas espaciales, en donde la exploración gráfica posibilita identificar regularidades, contrastes y anomalías en matrices de datos que de otro modo, permanecerían ocultas. Es por ello que el proceso de visualización constituye una herramienta cognitiva y analítica central en el flujo reproducible de investigación ecológica, exigiendo un entrenamiento continuo y la definición de protocolos reproducibles (Cleveland, 1993; Tufte y Graves-Morris, 1983; Wickham, 2016).

Los ejercicios que se desarrollan en este capítulo emplean las mismas bases de datos del capítulo anterior: ensamblajes de mesozooplancton en ambientes estuarinos y macroinvertebrados acuáticos de ecosistemas fluviales, enfocado a la representación gráfica de los datos que busca:

  • Identificar cambios en la estructura y composición del ensamblaje de cada grupo evaluado, en función de variables como salinidad, temperatura o estratificación vertical.

  • Explorar la distribución de grupos evaluados a lo largo de gradientes ambientales discretos o continuos.

  • Generar evidencia visual que oriente decisiones de muestreo en estudios similares, orientados al monitoreo o a la modelación ecológica.

Objetivo general

Desarrollar la capacidad de explorar e interpretar datos ecológicos mediante herramientas de visualización gráfica en R, utilizando ggplot2 como base para la estructuración eficiente y replicable de los procedimientos gráficos.

Objetivos específicos

  • Comprender la utilidad de la visualización como herramienta exploratoria bajo diferentes escenarios de análisis ecológico y ambiental.

  • Seleccionar las estrategias de visualización más adecuados según la naturaleza de las variables (cuantitativas o categóricas).

  • Construir representaciones gráficas reproducibles mediante el entorno ggplot2, enfatizando en la exploración de relaciones, asociaciones y diferencias en los datos.

  • Analizar posibles gradientes o agrupamientos en las estructuras ecológicas visualizadas.

  • Utilizar la visualización gráfica como el paso inicial para la formulación de hipótesis y la toma de decisiones posteriores.

Procedimiento de la exploración

  • Crear directorios de trabajo para guardar figuras y tablas generadas, librerías requeridas.

  • Cargar librerías y la base Insectos (usar diferentes opciones para practicar)

  • Explorar asociaciones o relaciones (figuras de elipses, pares, dispersión y coplot).

  • Explorar diferencias (figuras de barras o columnas y de cajas).

  • Realizar las opciones gráficas relacionadas a los objetivos.

  • Realizar transformaciones de los datos, para mejorar la visualización de patrones.

  • Practicar con leyendas y resultados de la visualización realizada.

A. Caso guiado: Macroinvertebrados bentónicos fluviales

Este caso guiado consiste en analizar de forma gráfica a ensamblajes de macroinvertebrados bentónicos asociados a gradientes físico-químicos del río Gaira, en Santa Marta.

El objetivo se orienta en trasladar la lógica de la visualización ecológica a un contexto enfocado en comparar distribuciones que permitan identificar patrones de dominancia, explorar relaciones entre variables revela gradientes ambientales, y seleccionar representaciones adecuadas facilita la interpretación de la estructura del ensamblaje.

Este ejercicio consolida la visualización como una herramienta central para el análisis ecológico, permitiendo interpretar la organización de las comunidades biológicas en sistemas ambientalmente heterogéneos.

1. Figuras de elipses

El Paquete corrplot es el que permite realizar las opciones gráficas de elipses a color, ingresar a este enlace:

corrplot

Otro enlace a corrplot:

corrplot

Las figuras de correlación realizadas con el paquete corrplot, son una buena opción para evaluar los patrones generales de relaciones positivas (azul) y/o negativas (rojo), entre parejas de variables. Funcionan para objetivos orientados en la relaciones de (1) variables biológicas, (2) variables ambientales y (3) variables biológicas con las ambientales.

# Elipses con colores
M <- cor(datos[,3:10])            # Matriz de Correlación (M)

La Figura 2 muestra la relación entre las variables, a partir de figuras de elipses y de circulos.

# Elipses con colores
par(mfrow = c(1,2), mar = c(3, 3, 2, 1))

corrplot(M, method = "ellipse")  # Figura de correlaciones con elipses

# Elipses con colores
corrplot(M, method = "circle")   # Figura de correlaciones con circulos

par(mfrow = c(1,1))

La Figura 3 muestra la relación entre las variables, a partir de figuras de elipses, además incorpora al nivel de correlación entre las parejas de variables con los coeficientes de Pearson.

# Elipses con colores
corrplot.mixed(M, upper="ellipse")

La siguiente opción de correlación (Figura 4), presenta un código más compejo que las anteriores, pero permite generar una visualización más completa de las relaciones entre parejas de variables y sus coeficientes de correlación de Pearson (también se pueden probar otros coeficientes como Spearman o Kendall).

corrplot(M,  method = "circle",            # Correlaciones con circulos
         type = "lower", insig="blank",    # Forma del panel
         order = "AOE", diag = FALSE,      # Ordenar por nivel de correlación
         addCoef.col ="black",             # Color de los coeficientes
         number.cex = 0.8,                 # Tamaño del texto
         col = COL2("RdYlBu", 200))        # Transparencia de los circulos

La siguiente figura de correlaciones (Figura 5) es apropiada para casos en los que tenemos muchas variables biológicas (ej. tipos de taxones) e interesa evaluar su relación con las variables ambientales.

# Elipses con colores
M1 <- cor(datos[,3:4], datos[,5:10])            # Matriz de Correlación (M)

# Elipses con colores
corrplot(M1, method = "ellipse", type="upper")

3. Figuras de Dispersión por pares de variables (pairs)

El Paquete pairs es el que permite realizar las opciones gráficas de dispersión por parejas de variables, ingresar a este enlace:

pairs

Otro enlace a pairs:

pairs

Los gráficos de pares son complementarios a los de correlación, pero permiten conocer otros detalles en las relaciones entre parejas de variables (ej. relaciones lineaes vs. suavizadas o loess). En la siguiente figura (Figura 6), además de visualizar si la dispersión de los puntos se orienta hacia una relación positiva o negativa, entre más se ajuste la línea verde (tendencia lineal), con la negativa (tendencia no lineal, suavizada o loess), se puede precisar mejor, si hay una verdadera relación lineal entre las parejas de variables en comparación.

A continuación se presenta una variante a las figuras de pares (Figura 6), que por medio de la función panel, permite incorporar otros elementos en la matriz gráfica, como histogramas para visualizar el patrón de simetría de cada variable y el valor de correlación con coeficientes como el de Pearson. Las líneas rojas definen la relación no lineal o suavizada (loess o lowess) entre las parejas de variables.

# Correlaciones de Pearson
library(SciViews)

pairs(datos[,c(3,5,7,8,10)], diag.panel = panel.hist, 
      upper.panel = panel.cor, lower.panel = panel.smooth)

6. Coplot

Las figuras de coplot, permiten relacionar a tres variables, en donde una de ellas puede ser continua o discreta, mediante segmentaciones.En la Figura 15 se incorporan regresiones suavizadas (loess). Seis páneles en la relación pH y Efemerópteros se asocian a seis barras de temperatura, en donde el primer panel de la parte inferior se correlaciona con la primera barra de temperatura, ubicada a la izquierda y así sucesivamnte.

# Coplot con líneas de ajuste suavizado (loess)
with(datos, {
  coplot(Efem~pH|temp,
         panel = panel.smooth)})

Para este caso (?@fig-fig27), se realiza una categorización de dos variables contínuas, que permitirán construir el coplot sin solapamiento de las barras de la tercera variable. Las relaciones se proyectan de forma lineal y el la siguiente ifura serán de forma suavizada.

Categorización de las variables ambientales

Este método divide la variable en tres partes iguales (terciles) utilizando los cuantiles de la distribución. En el siguiente ejercicio se crea una variable categórica llamada temp_Level.

# Categorización de la temperatura
datos <- 
  datos %>%
  mutate(clasetemp = case_when(
    temp <= quantile(temp, 1/3, na.rm = TRUE) ~ "T.Baja",
    temp <= quantile(temp, 2/3, na.rm = TRUE) ~ "T.Media",
    temp <= quantile(temp, 3/3, na.rm = TRUE) ~ "T.Alta"
  ))

# Categorización del pH 
datos <- 
  datos %>%
  mutate(clasepH = case_when(
    pH <= quantile(pH, 1/3, na.rm = TRUE) ~ "pH.Bajo",
    pH <= quantile(pH, 2/3, na.rm = TRUE) ~ "pH.Medio",
    pH <= quantile(pH, 3/3, na.rm = TRUE) ~ "pH.Alto"
  ))

# Resumen estadístico "datos_resum"
datos_resum <- datos %>%        # Base de datos resumida
  group_by(cuenca) %>%          # Factor o variable agrupadora
  summarise(datos.m = mean(Ab),   # Media de cada grupo del factor

            datos.var = var(Ab),  # Varianzas de cada grupo
            n.Ab = n(),           # Tamaño de cada grupo
